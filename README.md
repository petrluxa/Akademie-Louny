# Tenisová akademie Louny — návrhy nového webu

**Náhled:** https://petrluxa.github.io/Akademie-Louny/

Tři návrhy úvodní stránky nového webu akademielouny.cz, každý s vlastní náladou
a vlastním konceptem loga a odznaku Partnerský klub:

- **01 Kurt** — světlá moderní
- **02 Erb** — světlá klasická
- **03 Hala** — tmavá moderní

Obsah náhledů je zčásti ukázkový (termíny, trenéři, kontakty, partneři) a fotky jsou ilustrační
(Unsplash, Pexels). Mapová data © přispěvatelé OpenStreetMap.
